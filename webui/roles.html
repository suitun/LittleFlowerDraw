角色库触发词

登记/查看模板必须且只能包含一个 {角色名}，角色列表模板不能带占位符。模板开头加 @ 表示必须先 @ 机器人，例如 @小花小花这是 {角色名} 或 @小花记得谁。

角色库限制
绘图指令

多人替换用 @ 分隔角色，例如 多人穿@角色1@角色2@角色3 换装；自由绘画不依赖角色库，可以不带参考图。模板开头加 @ 表示必须先 @ 机器人，例如 @变{角色名} {额外提示词}。

提示词必须明确图1是底图、后续图片只是角色外观参考。参考图是头像或表情包时，建议「绘图 API → 尺寸」选 reference，避免输出被角色立绘的比例带偏。
